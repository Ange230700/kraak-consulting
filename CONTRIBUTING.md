# Contribution

## Table des matières

- [Contribution](#contribution)

Le guide de contribution actif est
[`docs/engineering/CONTRIBUTION_WORKFLOW.md`](docs/engineering/CONTRIBUTION_WORKFLOW.md).

Rappels rapides :

- créer les branches courtes depuis `main` ;
- ouvrir les PR de travail vers `main`, seule branche permanente ;
- déployer uniquement des tags SemVer accessibles depuis `main` ;
- valider localement et en CI sans environnement distant permanent de test ;
- ne jamais utiliser `--no-verify`.
